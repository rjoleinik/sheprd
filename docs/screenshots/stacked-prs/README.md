# Stacked pull requests

Native captures of an isolated fixture window (Catppuccin Mocha) for the stacked pull request work: the pull request page's stack chip and popover (blocked, ready, queued, inferred), the sidebar badge, and the Git popup's restack, stacked merge, and merge queue dialogs. The fixture reads no daemon, credentials, or GitHub; its data is `example/project` and the sidebar's test workspaces.

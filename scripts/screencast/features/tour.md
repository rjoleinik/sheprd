# Welcome to Sheprd
fr: Bienvenue dans Sheprd

## 1
en: This is Sheprd: one window for your terminals and your coding agents.
fr: Voici Sheprd : une seule fenêtre pour vos terminaux et vos agents de code.

## 2
en: Each project gets a workspace in the sidebar, with real terminals in tabs.
fr: Chaque projet a son espace de travail dans la barre latérale, avec de vrais terminaux en onglets.

## 3
en: Start an agent with the button next to the new tab button, and ask for a change.
fr: Lancez un agent avec le bouton à côté du nouvel onglet, et demandez une modification.

## 4
en: It works in the open: every file it reads, every edit, and every test it runs.
fr: Il travaille sous vos yeux : chaque fichier lu, chaque modification, chaque test lancé.

## 5
en: When it's done, Review Changes shows exactly what changed.
fr: Une fois terminé, « Relire les changements » montre exactement ce qui a changé.

## 6
en: Read it line by line, and leave notes the agent picks up.
fr: Relisez ligne par ligne, et laissez des notes que l'agent reprendra.

## 7
en: And Command Shift P opens the palette: everything Sheprd does, one search away.
fr: Et Commande Majuscule P ouvre la palette : tout ce que fait Sheprd, à une recherche près.

## 8
en: That's the basics. Every feature has its own short guide below.
fr: Voilà l'essentiel. Chaque fonctionnalité a son propre petit guide ci-dessous.
